# Asset Return & Redeployment — Operational Checklist

A generic operational checklist for processing a returned device. Contains no
site names, locations, routing or product detail.

## 1. Receipt

- [ ] Device received and logged.
- [ ] Accessories and condition recorded.
- [ ] Assigned a tracking reference in the inventory system.

## 2. Technical assessment

- [ ] Power-on and basic function check.
- [ ] Condition classified: reusable / damaged / quarantined / disposal-bound.
- [ ] Repairable-versus-dispose decision recorded for damaged items.

## 3. Secure wipe (generic)

- [ ] Data securely erased per the standard procedure.
- [ ] Wipe completion recorded against the tracking reference.

## 4. Reimage

- [ ] Device reimaged to the current baseline.
- [ ] Updates applied.

## 5. Quality checks

- [ ] Post-image validation completed (see Project 01 checklist).
- [ ] Any failures logged and re-processed.

## 6. Storage

- [ ] Device stored in the correct operational stock category.
- [ ] Stock level reviewed; low-stock control triggered if needed.

## 7. Redeployment

- [ ] Device allocated to a user or site.
- [ ] Records updated to reflect redeployment.
