# Project 04 — Multi-Site IT Asset Return & Redeployment Workflow

## Executive summary

Designed and documented an end-to-end workflow for returned and offboarded IT
assets, covering receipt, technical assessment, secure wiping, reimaging, quality
checks, storage and redeployment. The workflow was applied across three sites and
created a structured foundation for wider regional standardisation.

## Operational challenge

Returned and offboarded devices were handled inconsistently, leading to missed
steps, repeated firefighting and delays getting equipment back into operational
stock. There was no shared, documented flow spanning receipt through to
redeployment.

## My contribution

- Designed and documented an end-to-end workflow for returned and offboarded IT
  assets.
- Covered receipt, technical assessment, secure wiping, reimaging, quality
  checks, storage and redeployment.
- Defined process maps, physical asset flow, responsibilities, storage
  organisation, routing and low-stock controls.
- Applied the workflow across **three sites**.

## Approach

- Mapped the full lifecycle from receipt to redeployment as an explicit,
  repeatable flow.
- Defined decision gates for damaged, reusable, quarantined and disposal-bound
  equipment.
- Assigned clear responsibilities using a RACI model.
- Added low-stock controls so replenishment was triggered before stockouts.

## Outcomes

- Workflow applied across **three sites**.
- Helped reduce missed steps, repetitive firefighting and delays returning
  devices to operational stock.
- Created a structured foundation for wider regional standardisation.

## Security and confidentiality considerations

- Secure wiping is described only in generic terms; no specific product,
  configuration, storage location or routing is named.
- No site names, internal locations or asset formats are included.

## Lessons learned

- Explicit decision gates (reusable / damaged / quarantined / disposal) removed
  most of the ambiguity that previously caused rework.
- Low-stock controls turned replenishment from reactive firefighting into a
  planned step.
- Documenting the flow once and applying it across sites was the basis for later
  regional standardisation.
