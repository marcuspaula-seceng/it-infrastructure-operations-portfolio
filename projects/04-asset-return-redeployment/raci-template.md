# Asset Return & Redeployment — RACI Template (Generic)

A generic RACI template for the asset return and redeployment workflow. Roles are
generic placeholders; adapt them to a real organisation as needed.

**R** = Responsible · **A** = Accountable · **C** = Consulted · **I** = Informed

| Stage | Service Desk | IT Technician | Asset Management | IT Operations Lead |
|-------|:-----------:|:-------------:|:----------------:|:------------------:|
| Receipt and logging | R | C | A | I |
| Technical assessment | I | R | C | A |
| Secure wipe | I | R | C | A |
| Reimage | I | R | I | A |
| Quality checks | I | R | C | A |
| Storage & stock control | I | C | R | A |
| Redeployment | R | C | C | A |
| Disposal routing | I | C | R | A |

## Notes

- Exactly one **Accountable** role per stage.
- Roles are generic and do not reflect any specific organisation or individual.
- Adapt role names, and split or merge stages, to fit local structures.
