# LinkedIn Project Copy

Concise, LinkedIn-ready summaries of the five case studies. All figures are
documented operational outcomes, not independently audited guarantees. All
demonstration artefacts use synthetic data.

---

## Endpoint Imaging Infrastructure Optimisation — Linux & Windows

Improved a Linux and Windows endpoint-imaging environment. Upgraded imaging
servers, kept OS builds current, and introduced a test instance for daily image
validation. Standardised wipe-and-reimage procedures and repeatable post-image
checks (camera, microphone, audio, networking, Windows and vendor updates).
Increased imaging-network capacity from 100 Mbps to 1 Gbps and reduced individual
device turnaround from approximately 60 minutes to 15 minutes. Collaborated with
teams in Singapore and China to test image versions and improve reliability.

*Skills: Endpoint Management · Operating System Deployment · Windows · Linux ·
Server Administration.*

---

## Dublin IT Asset Management & Audit Automation

Contributed to the design and implementation of a scan-based asset-tag and
automated audit process for Dublin IT stock operations. Introduced a standardised
workflow that improved asset identification, inventory traceability and audit
consistency, and reduced repetitive manual checks and human error. Supported
validation across an environment of more than 5,000 assets, contributing to 99%
stock and audit visibility. Provided operational requirements and a spreadsheet
model that contributed to an application later developed by a colleague. The
Dublin process became a reference model across EMEA.

*Skills: IT Asset Management · Process Automation · IT Audit · Inventory
Management · Microsoft Excel.*

---

## Enterprise Virtualisation & Server Infrastructure Deployment

Supported server and virtualisation infrastructure deployment for an enterprise
environment. Installed server storage and 10 Gb network adapters, deployed VMware
vSphere and vCenter, and provisioned Linux and Windows virtual machines.
Supported cluster, RAID, storage, application and network configuration, and
participated in testing and troubleshooting. Helped deliver a stable virtualised
environment for operational use and future expansion.

*Skills: VMware vSphere · Virtualisation · Server Administration · Network
Infrastructure · Linux.*

---

## Multi-Site IT Asset Return & Redeployment Workflow

Designed and documented an end-to-end workflow for returned and offboarded IT
assets, covering receipt, technical assessment, secure wiping, reimaging, quality
checks, storage and redeployment. Defined process maps, physical asset flow,
responsibilities, storage organisation, routing and low-stock controls. Applied
across three sites, it helped reduce missed steps, firefighting and delays
returning devices to operational stock, and created a foundation for wider
regional standardisation.

*Skills: IT Asset Lifecycle Management · Process Improvement · IT Operations ·
Technical Documentation · Service Delivery.*

---

## Dublin Lark & Zoom Meeting Room Readiness Programme

Performed operational readiness and validation checks across 19 documented
meeting rooms at a Dublin site. Tested room schedulers and controllers, displays
and projectors, cameras, microphones, speakers, audio/video quality, HDMI
connectivity and wireless screen sharing. Validated Lark and Zoom functionality,
including switching between platforms. Documented issues and completed fixes,
helping maintain reliable meeting-room services during the transition and
coexistence of Lark and Zoom.

*Skills: Unified Communications · Video Conferencing · Audiovisual Systems · Lark
Suite · Technical Support.*
