# Security Policy

## Scope

This repository contains only documentation and sanitised demonstration
artefacts using synthetic data. It exposes no service, endpoint or credential.

## Reporting a vulnerability or a confidentiality concern

If you find a security issue in the demonstration code, or you believe any
content inadvertently discloses confidential or personal information, please:

1. Open a GitHub issue **without** including sensitive details, or
2. Contact the maintainer via the links in the [README](README.md).

Confidentiality concerns are treated with priority and affected content will be
reviewed and, where appropriate, removed.

## What not to send

Please do **not** include real credentials, tokens, internal hostnames, IP
addresses, asset tags or personal data in any issue or pull request. Use
synthetic examples only, consistent with [CONFIDENTIALITY.md](CONFIDENTIALITY.md).

## Supported content

Only the latest state of the `main` branch is maintained.
